1. **C comes from Im z_k only.** A uniform series resistance r on all four ports (Z′ = Z + r·I) shifts every z_k by exactly r (F is unitary, F·I·F^H = I), so C_1 is unchanged; a uniform series reactance jX shifts Im z_1 and moves C_1. The PEC and solid σ = 800 Studies show the same thing physically: Re z_1 is 0.025 Ω against 5.97 Ω (≈ 240×, the solid conductor's loss), while C_1 moves only −6.98 % (`:945`, `:2761`).
2. **What C_mode tunes.** Adding the series capacitor 1/(jωC_1) on every port (Z_t = Z + I/(jωC_1)) cancels Im z_1 (and Im z_3, the degenerate partner) exactly, and leaves mode 2 with Im z_2 − 1/(ωC_1) < 0 (predicted ≈ 25.19 − 37.53 = −12.3 Ω, from `:945`).
