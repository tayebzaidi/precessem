# OPS-55 — `evaluate_vector_field_parallel` refuses equal-count point lists whose coordinates differ across ranks

 **`evaluate_vector_field_parallel` refuses equal-count point lists whose coordinates differ across ranks** — opened 2026-09-19 (interactive session, from an external code review; the same class as `OPS-40`, in the form its count guard cannot see). `post/evaluation.py` allgathers only `n_points`; each rank then locates and evaluates **its own** copy of the points and rank 0 scatters the hits by positional index, so with equal counts and different coordinates `values[i]` is the field at some other rank's row `i`, reported against rank 0's — all-valid mask, plausible numbers, no error; where two ranks both claim row `i` the last gathered wins. **Latent, not live:** a survey of the ≈58 calling files found every current caller passing identical points (the one site building points from rank-local mesh data, `tests/validation/test_birdcage_b1_plus_closed_form.py:729–741`, gathers and broadcasts first); the realistic trigger is a fixed-N rank-local list (unseeded `np.random.rand(N, 3)`, `mesh.geometry.x[:N]`). **Plan.** (1) Validate, do **not** broadcast — broadcasting rank 0's points would hide a caller that still indexes the result against its own local `points`. Fold a digest into the existing collective: `comm.allgather((n_points, hashlib.blake2b(points.tobytes()).digest()))` — no extra round on the valid path. (2) Counts equal but digests differing is known on every rank, so the error path may use further collectives safely: bcast rank 0's points, each rank computes its first differing row and max abs deviation, allgather, and raise `ValueError` on **every** rank with the per-rank figures — the magnitude separates rank-local points (gross) from rank-dependent floating-point ordering (≈1e-16); the message says to broadcast the points from rank 0. The count-mismatch message and the shape check are unchanged. (3) Bitwise identity is the documented contract; a caller differing only in the last bit would begin to raise — none found, and that raise is correct. **Done-when (§4):** in `tests/post/test_evaluation_collective_guard.py`, at `-n 1` and `-n 2`: equal counts with coordinates shifted by `0.01 * rank` inside the unit cube raise on every rank (allgathered flags `== [True] * size`), the message naming each rank's first differing row and deviation, and at `-n 1` the same construction does **not** raise (negative control); a pre-change control — the function at the pinned pre-change sha, `git show` into a scratch module under `/logs/` as `OPS-53` did — returns an all-valid mask on that input **and** values deviating from the closed form `(x, 2y, 3z)` at rank 0's points by the amount the shift predicts (quantitative: the defect was silent, and by how much); the existing identical-list test still green at `< 1e-12`.
