# WF-18 — rename to PrecessEM

Item briefs and execution history (operator directive 2026-10-01). The §7 row is the status of record.

## Origin — operator directive 2026-10-08 (interactive session)

The human operator chose a project name to replace `femem` / `fem-em-solver`
ahead of Phase 9's v0 and the repository going public:

| Surface | Today | After |
|---|---|---|
| Brand, README title, docs site | FEM-EM Solver | **PrecessEM** |
| Import package | `fem_em_solver` | **`precessem`** |
| Distribution (`pyproject.toml` `name`) | `fem-em-solver` | **`precessem`** |
| CLI (`[project.scripts]`) | `femem` | **`precess`** |

Why the name: precession at the Larmor frequency is what every coil here is
tuned to; the "EM" suffix says the code solves the RF field, not spin
dynamics. In prose always write it capitalised, **PrecessEM** — lowercase
`precessem` is easy to misread as "process".

**Availability checked by the operator 2026-10-09:** `precess` and
`precessem` are free on PyPI; `PrecessEM` is free on GitHub (unrelated repos
named `precess` exist under other owners — no conflict, repository names are
per owner). No fallback needed.

## Scope

In:

- `src/fem_em_solver/` → `src/precessem/` (`git mv`, history kept), every
  import in `src/`, `tests/`, `examples/`, `scripts/`, `docs/` code blocks.
- `pyproject.toml`: distribution name, `[project.scripts]` `precess =
  "precessem.cli:main"`, plus `femem` as an alias for one release.
- **Compatibility shim:** a thin `fem_em_solver` package that re-exports
  `precessem` and its submodules (a meta-path alias, so
  `import fem_em_solver.post.evaluation` resolves to the same module object)
  and emits one `DeprecationWarning`. Removed one release after v0.
- `WF-14`'s validation-envelope registry and public-surface snapshot under
  the new name (node IDs change path; the mapping itself does not).
- Generated API pages (`WF-17` step 2) regenerated; user guide and README
  prose use PrecessEM.
- `src/sitecustomize.py`, environment tests and any string that names the
  package path.

Out (not this chunk):

- Docker service / container / image names (`fem-em-solver`,
  `fem-em-solver-xl`, …): the automation launchers, the bash guard, the XL
  queue files and `run_and_log.sh` usage in hundreds of plan lines name them.
  A separate infra chunk if ever wanted.
- The repo directory and the GitHub repository name (operator).
- History: PROJECT_PLAN, chunk files, attempts.md, known-issues, harness logs
