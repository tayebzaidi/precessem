### Item 63 (T10 Route B, `attempt/ANS-7-T10-routeB-20260929T021420Z`) — ruled: land it

**Anchor (3): the red was the item's drafting error, not a code defect,
and the re-routed check is a *record*.** On the lumped-sheet route,
`run_n_port_sparameter_sweep` returns as `z_matrix` the **terminated**
transimpedance, V_i / I_k with every undriven sheet in 50 Ω. That
matrix is documented as "a diagnostic, never as S's source"
(`src/fem_em_solver/ports/sparameters.py:347–356`, `:484–493`). S comes
from power waves. The open-circuit Z of the returned S is
z0(I + S)(I − S)⁻¹, and the terminated matrix is not that Z, so the
first W1's 6–307× gap (`20260929T021845Z_ANS-7-W1-B1.log:3624–3648`,
largest at resonance, where termination matters most) is the expected
result of feeding the wrong matrix. Item 63's anchor (3) said "the SPEC's
Z formula" without saying which Z, and the review wrote that.

After the fix, both sides derive from one S: the S-domain termination
reduction (`tuned_input` → `reduce_terminated_ports`) and a Z-domain Schur
complement. They agree for any S in exact arithmetic. That makes the check
true by construction with respect to the fixture: it validates the circuit
layer's algebra, not the field solve. Under rule (h) it is a **record**. The
script may keep asserting it (5.334e-13 against 1e-9, `…022842Z_ANS-7-W2-B2.log:2818`)
as a code-consistency check, but it counts toward no gate. It is also not
in `ANS-7`'s v2 Done-when, which asserts reciprocity, the copper identity,
one − → + zero per column and (item 68) Route A = Route B. All of those that
item 63 could reach are green (W2 `:2819–2822`: Cu `f₀` 63.983031 MHz, PEC
63.997103 MHz; k = ±1 share 0.999994 / 0.999998). No known-issues entry is
needed. The `z_sweep` key the stage file keeps is the terminated
transimpedance, and the guide should say so.

**Q miss: a mis-imported prediction, not a failure.** Printed Q is
918.44 (Cu) and 1535.95 (PEC) (W2 `:2819`, `:2822`) against "≈ 68". That
prediction came from item 50's **v1** measurement, which was a different
circuit: 15.57 pF on three gaps, bare feed, series resonance, Q 62.5 / 64.2.
Rule (e) makes it a printed reading. The item never gated it, so the v2
