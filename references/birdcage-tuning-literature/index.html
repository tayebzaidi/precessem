    Birdcage tuning — how the field does it (literature note)¶

    Collected 2026-09-28 (interactive session, operator request) while deciding how to choose the ring capacitor for the human-scale birdcage (WF-10, §10 chain H8′). Public literature only — tracked, citable from the plan. Read depth is stated per entry: "read" means the page itself was fetched and read; "abstract / snippet" means only a search-result summary was seen, so check the paper before leaning on a detail.

    The finding in one paragraph¶

    The standard workflow for tuning a birdcage (or any multi-capacitor MRI coil) is EM / RF-circuit co-simulation: every capacitor site becomes a 50 Ω port in one driven full-wave solve (HFSS, CST, …); capacitors are then chosen in the circuit domain, and fields for any tuning are rebuilt by superposition. The capacitor is chosen for a mode — either by construction (a circuit model that targets the k = 1 current pattern) or by an optimiser whose cost includes field homogeneity, with the mode then confirmed from the capacitor-current pattern (≈ sinusoidal around the end ring for k = 1). Full-wave eigenmode solves are used to analyse the mode spectrum, less to tune a loaded, lossy coil (the problem is complex and, with lumped capacitors, frequency-dependent). Lumped-element models alone break down at high field, which is why co-simulation replaced them.

    What this repo does with it (operator ruling 2026-09-28, §10 H8′): our PORT-15 circuit layer is co-simulation. On a C16-symmetric coil the port matrix splits exactly by azimuthal harmonic, so the k = 1 mode is tuned in its own block (C = 1 / (ω Im λ₁)), checked against an in-model solve and a k = ±1 current share ≥ 0.9 — the "choose for a mode, confirm by current pattern" step of the literature, done with linear algebra instead of an optimiser. TH-17 T5a/T5b did the same on F-small and confirmed it against a true eigensolve.
