    Why this fixture is exact, not approximate. The z-invariant reduction is Jin §1.4.2 (eqs (1.44), (1.45), 01_basic-electromagnetic-theory.md:265–277) and §11.2.1 eq (11.53) (11_fem-eigenfunction-expansion-methods.md:361): ϕ = E_z for E_z-polarisation, ϕ = H_z for H_z-polarisation. A finite slab of the infinite problem reproduces the infinite solution exactly when every boundary condition is one that the exact z-invariant field already satisfies. With the solve well posed (lossy host), the FEM's continuous solution is then the closed form, and only discretisation and faceting remain. - TM_z, n = 0 (E = E_zẑ, H = H_φφ̂). On a plane z = const, n̂ = ±ẑ: - n̂ × E = 0 identically, so the PEC end condition (Jin §1.5.2 eq (1.52), 01:315–321; the Dirichlet "electric wall" n̂ × E = 0, 08_vector-finite-elements.md:1533) is exact. - n̂ × H = ∓H_φ ẑ × φ̂ ≠ 0, so the natural end (the Neumann "magnetic wall" n̂ × (∇ × E) = 0, 08:1533; core/time_harmonic.py:345–348 "NATURAL … is PMC") is wrong: it forces H_φ = 0 on the ends and breaks z-invariance. - The ends are therefore tag 3 constrained: pec tags (1, 2, 3). - TE_z, n = 1 (H = H_zẑ, E transverse). On the end planes: - n̂ × E = (E_x, E_y) rotated ≠ 0, so a PEC end is wrong. - n̂ × H = H_z ẑ × ẑ = 0, so the natural (PMC) end is exact. - The ends are tag 3 left out: pec tags (1, 2). - This is the step-0 brief's assignment (:92–93), and the §7 row's ("end planes PEC (TM) or natural/PMC (TE)"). The opposite pairing (PMC ends for E_z, PEC for TE) is the trap, not the fixture. - Truncation. The outer wall ρ = c carries the exact total field's tangential trace from step 0, so it is exact at finite k. Jin's own §11.2.1 route, the global third-kind condition (11.61)/(11.63) from the outgoing expansion (11.56), is not implemented or tested here. Imposing the exact trace is the IMP-1 step 3(b) idiom, and it removes truncation from the error budget. - The sizing rule does not bind.
