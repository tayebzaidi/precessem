    OPS-64 — xl-run.sh establishes "no orphans" itself and handles a window's declared outputs¶

(a) Every ANS-4-family ledger row since 09-20 reads "orphans: not established": the before / after rank count lives in the command of the newer entries, not in the launcher, so a queued entry without it cannot prove the wrapper's death left nothing running (CLAUDE.md hard rule, measured 2026-09-09).
