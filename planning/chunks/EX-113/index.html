    The angle: what tune reads, what it ignores, and which mode it tuned. The gate checks the number against TH-17. This example adds three readings no example has; the first two are exact circuit identities (asserted), the third is a field picture (printed). 1. C comes from Im z_k only. A uniform series resistance r on all four ports (Z′ = Z + r·I) shifts every z_k by exactly r (F is unitary, F·I·F^H = I), so C_1 is unchanged; a uniform series reactance jX shifts Im z_1 and moves C_1. The PEC and solid σ = 800 Studies show the same thing physically: Re z_1 is 0.025 Ω against 5.97 Ω (≈ 240×, the solid conductor's loss), while C_1 moves only −6.98 % (:945, :2761). 2. What C_mode tunes. Adding the series capacitor 1/(jωC_1) on every port (Z_t = Z + I/(jωC_1)) cancels Im z_1 (and Im z_3, the degenerate partner) exactly, and leaves mode 2 with Im z_2 − 1/(ωC_1) < 0 (predicted ≈ 25.19 − 37.53 = −12.3 Ω, from :945). This is a circuit-layer statement at 64 MHz on one degree-1 fixture — no resonance, f₀, Q or tuning-accuracy claim (§2; ANS-7 stays 🟡). 3. The mode fields. Study.b1_plus() returns one CG1 B per port drive. Superposing them with the DFT weights v_p = conj(F[k, p]) = e^{+2πi k p/4}/2 gives the incident-wave mode-k field (S is near-circulant, off-diagonal residual 3.8e-05, so a mode-k incident vector excites mode k). Printed: |B₁⁺| and |B₁⁻| at the coil centre for k = 1 and k = 3 (one co-rotating, one counter-rotating — which is which is the e^{jωt} convention, printed, not claimed), and |B_k=2(0)| / |B_k=1(0)| (predicted ≲ 1e-2: the k = 2 transverse field has a null on the axis in the C4-symmetric limit; first measurement).
